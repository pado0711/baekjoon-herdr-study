# 백준 Python 학습 로드맵

Herdr Desktop(`herdr-app`, `hc`)과 Python 3이 필요합니다. 개념 그림과 질문 기능에는 로그인된 Codex CLI를 사용합니다.

```sh
git clone https://github.com/pado0711/baekjoon-herdr-study.git
cd baekjoon-herdr-study
./setup
```

`./setup`을 실행하면 **백준 학습 로드맵** 탭이 열립니다. 같은 저장소에서 다시 실행하면 기존 탭을 엽니다.

1. **새 로드맵 등록** 또는 **기본 8주 복사해 편집**을 선택합니다.
2. 제목과 학습 단계를 입력하고 문제 번호나 백준 문제 링크를 추가합니다. 본문에서 문제 순서와 복습 메모를 편집할 수 있습니다.
3. **저장하고 사용**을 누릅니다. `ROADMAP.local.md`에 저장되며 이후에는 **내 로드맵 편집**으로 수정할 수 있습니다.

Codex 학습 코치는 `ROADMAP.local.md`를 우선 읽고, 개인 로드맵이 없으면 `ROADMAP.md`를 사용합니다. 풀이 이력은 `PROGRESS.md` 템플릿에서 시작해 `PROGRESS.local.md`에 저장됩니다. 개인 로드맵, 풀이 이력, `solutions/`의 사용자 코드는 Git에서 제외됩니다.

로드맵의 문제 링크를 누르면 시각화, 편집기, 테스트를 한 탭에서 사용할 수 있습니다. **Codex CLI 열기**는 같은 탭 오른쪽에 대화용 터미널을 엽니다. 좁은 창에서는 화면 전환 버튼이 표시됩니다. **풀이 저장**은 `solutions/<문제번호>.py`에 저장합니다.

공식 문제 본문과 예제는 왼쪽의 **백준 원문 열기**를 눌러 브라우저에서 읽습니다. [백준 이용 규칙](https://help.acmicpc.net/rule)

## 문제 풀이와 복습

- **개념 그림 만들기**를 누르면 Codex가 문제에 맞는 작은 예시를 단계별로 보여줍니다. 문제 번호와 제목으로 조건을 알기 어려우면 공식 페이지에서 확인한 조건이나 학습할 개념을 한 줄 입력합니다. 만든 그림은 문제별로 저장됩니다. 2557번과 1000번은 기본 그림이 있고, 2178번에서는 분기 미로와 선택한 테스트를 BFS 그림으로 볼 수 있습니다.
- **테스트 실행**은 편집 중인 풀이를 저장한 뒤 로컬 Python으로 검증합니다. 기본 연습 케이스를 쓰거나 입력과 기대 출력을 직접 지정합니다. AI 학습 예시에 연습 케이스가 있으면 **연습 입력·기대 출력 채우기**로 가져와 값을 확인하고 실행할 수 있습니다.
- 테스트 후 **선택한 테스트**에서는 전달한 입력, 실제 출력, 기대값과의 비교를 순서대로 볼 수 있습니다. BFS 전용 그림이 있는 2178번의 작은 미로에서는 큐와 방문 상태도 확인할 수 있습니다.
- **이 단계 질문**을 눌러 그림의 단계를 연결한 뒤 오른쪽 터미널에 질문을 직접 입력합니다. 같은 문제의 후속 질문은 같은 터미널에서 이어가며, 창을 닫았다가 열면 그 문제의 최근 Codex 대화를 재개합니다. AC 기록 전에는 AI 연습으로 진행합니다.
- 막혔을 때 **접근 힌트**를 누르면 오른쪽의 같은 Codex CLI에서 핵심 접근, 이유, 구현 시 주의점, 복잡도를 볼 수 있습니다. 전송된 문제는 개인 로드맵의 **복습 우선**에 한 번만 추가됩니다. 다시 풀었으면 **내 로드맵 편집**에서 해당 항목을 지울 수 있습니다.
- **알고리즘 개념**은 이 문제에 관련된 개념의 정의와 작은 예시, 이해 확인 질문을 같은 CLI 대화에 요청합니다.
- **이 테스트 진단**과 **진단 요청**은 선택한 테스트와 실행 당시 코드에서 어려웠던 개념을 기록합니다. 같은 개념의 어려움이 서로 다른 문제에서 확인되면 **복습 추천**이 현재 로드맵에서 복습 문제를 고릅니다. **로드맵에 복습 추가**를 누르면 개인 로드맵의 **복습 우선**에 반영됩니다.
- 백준에서 AC를 확인했다면 **AC 확인함**으로 개인 학습 기록에 남길 수 있습니다.

테스트와 진단 기록, Codex CLI에 연결할 화면 정보는 각 저장소의 `.study/`에 저장됩니다. 터미널 대화는 Codex CLI의 세션 기록으로 관리됩니다.

로컬 회귀 검수는 저장소에서 `python3 -m unittest discover -s study`로 실행합니다.
