# 백준 Python 학습 워크스페이스

Herdr Desktop에서 **백준 문제를 고르고, Python 풀이를 테스트하고, 막힌 부분을 Codex에 질문**할 수 있는 학습 워크스페이스입니다. 문제 탭 하나에서 개념 그림, 편집기, 테스트 결과와 Codex CLI 대화를 함께 볼 수 있습니다.

기본 로드맵은 입출력부터 BFS, 동적 계획법, 이분 탐색까지 익혀 **solved.ac 실버 I**에 도달하는 것을 목표로 합니다. 문제를 직접 추가해 원하는 순서로 연습할 수 있습니다. [기본 8주 로드맵](ROADMAP.md)

## 빠른 시작

Git과 Python 3, Herdr Desktop의 `herdr-app`과 `hc` 명령이 필요합니다. Codex 기능을 쓰려면 Codex CLI에 로그인해 두세요.

```sh
git clone https://github.com/pado0711/baekjoon-herdr-study.git
cd baekjoon-herdr-study
./setup
```

Herdr에서 **백준 학습 로드맵**이 열립니다. 같은 폴더에서 `./setup`을 다시 실행하면 기존 탭으로 돌아갑니다.

### 따라 해 보기 · 2178번 미로 탐색

1. 로드맵에서 **2178 미로 탐색**을 선택합니다. **백준 원문 열기**를 누르면 브라우저에서 공식 문제와 예제를 볼 수 있습니다.
2. **분기 예제**에서 **다음**을 눌러 큐에서 꺼낸 칸과 새로 추가한 칸을 비교합니다. **이 단계 질문**으로 오른쪽 CLI를 열고 “왜 이 두 칸이 같은 거리로 기록돼?”라고 물어보세요.
3. 편집기에 코드를 작성하고 **테스트 실행**을 누릅니다. **입출력 보기**에서 실제 출력과 기대 출력을 비교하고, 왼쪽 **선택한 테스트**에서 해당 미로의 BFS 상태를 봅니다.
4. 막히면 **접근 힌트**를 누릅니다. 힌트는 오른쪽 CLI에 표시되고, 문제는 로드맵의 **복습 우선**에 추가됩니다.

직접 만든 로드맵을 시험해 보려면 **1330번 두 수 비교하기**를 추가해 보세요. **개념 그림 만들기**로 조건 분기 예시를 열고, 입력 `2 5`와 기대 출력 `<`를 넣어 테스트할 수 있습니다.

## 기능

### 로드맵과 로컬 테스트

- **내 로드맵 만들기** · **새 로드맵 등록**이나 **기본 8주 복사해 편집**에서 문제 번호 또는 백준 URL을 추가합니다. **저장하고 사용**을 누르고, 순서나 복습 목록을 바꾸려면 **내 로드맵 편집**을 엽니다.
- **편집하고 테스트하기** · **풀이 저장**은 문제별 파일에 저장합니다. **테스트 실행**은 현재 코드를 저장한 뒤 기본 연습 케이스나 직접 입력한 케이스로 실행합니다. 표준 출력이 비어야 하는 케이스에는 **빈 출력 기대**를 선택하세요.
- **창이 좁을 때** · **개념 시각화**와 **편집기** 버튼으로 두 화면을 전환합니다.

### 개념 그림과 Codex 대화

- **작은 예시로 개념 익히기** · 2557번과 1000번은 기본 그림을, 2178번은 큐·방문·거리를 보여주는 BFS 그림을 제공합니다. 다른 문제는 **개념 그림 만들기**를 누르고, 필요하면 조건이나 배우고 싶은 개념을 한 줄 적습니다. 만든 그림은 문제별로 저장됩니다.
- **보는 단계나 테스트를 질문에 연결하기** · **이 단계 질문**은 선택한 그림 단계를 대화에 연결합니다. 테스트 케이스를 바꾼 뒤 **Codex CLI 열기**를 누르면 실행 당시 코드와 새로 선택한 케이스를 바탕으로 이어서 질문할 수 있습니다.
- **같은 문제의 대화 이어가기** · 후속 질문은 같은 CLI에서 진행합니다. 터미널을 닫았다가 열면 그 문제의 최근 대화를 재개합니다.

### 힌트와 복습

- **접근 힌트**는 풀이를 시작할 방향과 이유를 설명합니다. CLI에 요청이 전달되면 해당 문제를 **복습 우선**에 한 번 추가합니다.
- **알고리즘 개념**은 관련 개념을 작은 예시로 설명하고 이해 확인 질문을 냅니다.
- **풀이 진단**은 선택한 테스트와 실행 당시 코드에서 어려웠던 개념을 기록합니다. 같은 개념의 어려움이 여러 문제에서 확인되면 **복습 추천**에서 후보를 보고, **로드맵에 복습 추가**로 반영할 수 있습니다.

## 사용 조건과 개인 데이터

공식 문제는 백준에서 읽고 제출은 공식 페이지에서 직접 합니다. Codex 기능은 별도 연습과 풀이 후 복습에 사용하세요. AI가 만든 연습 케이스는 **연습 입력·기대 출력 채우기**로 불러온 뒤 값을 확인하고 실행합니다. 백준에서 AC를 확인했다면 **AC 확인함**으로 개인 진도에 기록할 수 있습니다. [백준 이용 규칙](https://help.acmicpc.net/rule)

| 로컬 경로 | 저장 내용 |
| --- | --- |
| `ROADMAP.local.md` | 개인 로드맵과 복습 우선 목록 |
| `PROGRESS.local.md` | 개인 진도와 AC 기록. `PROGRESS.md`는 시작 템플릿입니다. |
| `solutions/<문제번호>.py` | 직접 작성한 풀이 |
| `.study/` | 테스트 결과, 진단 기록, 생성한 그림과 Codex에 연결하는 자료 |

위 개인 파일은 Git 제외 대상입니다. 대화 이력은 Codex CLI가 로컬에서 관리합니다.
